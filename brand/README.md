# Mindris Brand Directory

This directory is reserved for official Mindris brand assets, source files, and guidelines.

## Purpose

Use this folder for:

- official logos
- wordmarks
- icons
- color references
- product visuals intended for reuse
- future brand guidelines
- design tokens used by documentation and product implementation

## Rules

- Do not assume brand assets are covered by the MIT License.
- Reuse of Mindris branding is governed by [`../TRADEMARKS.md`](../TRADEMARKS.md).
- Public forks and derivative services should rebrand unless they have written permission to use official Mindris identity.

## Suggested structure

Current structure:

```text
brand/
├── README.md
├── guidelines/
│   ├── brand-guidelines.md
│   └── design-tokens.json
├── icons/

```

## Current status

This folder now contains the baseline Mindris identity kit and its governance.

Add only source-controlled, intentional assets here. Do not place temporary exports or generated marketing files in this directory.
