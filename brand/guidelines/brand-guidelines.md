# Mindris Brand Guidelines

## Brand intent

Mindris is an operational AI workspace for candidate workflows.

The visual system should feel:

- precise
- calm
- technical
- trustworthy
- product-first

Avoid branding that feels playful, loud, overly futuristic, or decorative.

## Core identity

- Brand name: `Mindris`
- Extended name: `Mindris AI`
- Preferred product reference in UI: `Mindris`

Use `Mindris AI` for repository, legal, and descriptive contexts.

## Color system

### Core palette

- `Mindris Ink`: `#0F172A`
- `Mindris Blue`: `#2563EB`
- `Mindris Cyan`: `#06B6D4`
- `Mindris Cloud`: `#E2E8F0`
- `Mindris Mist`: `#F8FAFC`
- `Mindris White`: `#FFFFFF`

### Support neutrals

- `Slate 700`: `#334155`
- `Slate 600`: `#475569`
- `Slate 500`: `#64748B`
- `Slate 300`: `#CBD5E1`
- `Slate 200`: `#E2E8F0`
- `Slate 100`: `#F1F5F9`

### Semantic states

- Success: `#059669`
- Warning: `#D97706`
- Danger: `#DC2626`
- Info: `#0284C7`

## Usage ratios

- 70% neutral surfaces
- 20% ink and text structure
- 10% accent color

Accent colors should guide action and information hierarchy, not dominate whole screens.

## Typography

### Primary UI font

- `Inter`

### Editorial or long-form support

- `Merriweather`

Use `Merriweather` only for optional marketing, article, or long-form editorial material. Do not use it as the default product UI font.

### Type rules

- Headlines: semibold
- UI labels: medium
- Body: regular
- No negative letter spacing
- Keep product text compact and readable

## Logo system

Mindris uses a simple geometric mark paired with a wordmark.

### Preferred pairings

- Full-color logo on light backgrounds
- White logo on dark backgrounds
- Monochrome ink logo for print or restrained product contexts

### Clear space

Maintain clear space equal to the width of the icon square around the full logo.

### Minimum size

- Icon only: 20px
- Full logo: 96px wide

## Icon style

- Simple geometric forms
- Rounded corners, not soft blobs
- No gradients inside product navigation icons
- Product UI icons should continue using `lucide-react`

Brand icons are not a replacement for UI icons.

## Backgrounds and surfaces

- Default product surfaces stay light
- Dark surfaces are reserved for editors, previews, logs, and focused technical panels
- Avoid decorative gradients as primary page backgrounds
- Avoid purple-heavy or beige-heavy brand drift

## Motion

- Fast, subtle, purposeful
- Use fades and short transforms
- Avoid theatrical entrances

## Voice

Mindris copy should sound:

- direct
- competent
- practical
- calm

Avoid hype, vague claims, and inflated AI language.

## Do not

- distort the logo
- recolor the logo arbitrarily
- place the logo on low-contrast noisy backgrounds
- use the brand mark as decorative wallpaper
- apply multiple competing accent colors in one composition
